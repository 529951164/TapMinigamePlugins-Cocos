# TapTap 小游戏构建插件 v1.2.0 更新说明

## 新增功能

### 1. tap API 代码提示（零配置）

安装插件后，在任意 `.ts` 文件中输入 `tap.` 即可获得完整的代码补全和参数提示，无需任何额外配置。

覆盖约 135 个 API，包括：

| 分类 | 示例 API |
|------|----------|
| 开放接口 | `login` `getUserInfo` `authorize` `showShareboard` `getSetting` |
| 广告 | `createRewardedVideoAd` `createBannerAd` `createInterstitialAd` `createGridAd` |
| 成就/排行榜 | `createAchievementManager` `getLeaderboardManager` |
| 云存档 | `getCloudSaveManager` `getFileSystemManager` |
| 界面 | `showToast` `showModal` `showLoading` `showActionSheet` |
| 数据缓存 | `setStorageSync` `getStorageSync` `removeStorageSync` `clearStorageSync` |
| 网络 | `request` `downloadFile` `uploadFile` `connectSocket` |
| 生命周期 | `onShow` `onHide` `getLaunchOptionsSync` |
| 设备 | `vibrateShort` `getNetworkType` `setKeepScreenOn` `scanCode` |
| 媒体 | `createInnerAudioContext` `chooseImage` `createVideo` |

### 2. AI Skills（AI 辅助接入）

插件内置 3 份 SDK 接入指南文档，位于 `ai-skills/` 目录。配合 AI 编程工具（Claude Code、Cursor 等）可快速生成完整的 SDK 适配层代码。

| 文件 | 功能 |
|------|------|
| `tap-sdk-skill.md` | 生成基础模块：平台检测、登录、分享、排行榜、成就 |
| `tap-ad-skill.md` | 生成广告模块：激励视频、插屏、Banner |
| `tap-cloud-save-skill.md` | 生成云存档模块：本地优先 + 云端备份 + 定时同步 |

插件加载时会在控制台输出 AI Skills 的文件位置，方便开发者查找：

## 使用方式

1. 将插件 ZIP 导入 Cocos Creator 项目
2. 代码提示自动生效，输入 `tap.` 即可使用
3. 如需 AI 辅助生成代码，将 `ai-skills/` 下的文档提供给 AI 工具即可
