# TapTap小游戏构建工具

一键构建微信小游戏并自动转换为Tap小游戏格式。

## 使用方法

1. 打开 **项目 → 构建发布**
2. 选择平台：**微信小游戏**
3. ☑️ 勾选 **"转换为Tap小游戏"**
4. 点击 **构建**

## 输出结果

构建完成后生成：
- **微信小游戏**：`build/wechatgame/`
- **Tap小游戏**：`build/TapBuild/game.zip`

最终的 `game.zip` 文件可直接上传到Tap小游戏平台。

## 转换流程

自动完成10个步骤：
1. 验证路径
2. 复制项目文件
3. 处理配置文件
4. 注入插件
5. Babel代码转换
6. 注入运行时代码
7. WASM兼容性处理
8. Coverview设置
9. 版本检查文件
10. ZIP打包
